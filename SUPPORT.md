## A useful bug report

Include:

- operating system and Chiasm version;
- whether you installed a workflow test artifact or built from source;
- approximate collection size and local or network storage;
- the smallest steps that reproduce the problem;
- what you expected and what happened instead.

Do not attach music files, passwords, API keys, tokens, private URLs, or other secrets. Chiasm uses inherited Melodex library and playback components, so note if Melodex is also installed when describing a data or playback issue.

Use [GitHub Issues](https://github.com/DasManPack/chiasm/issues) for reproducible bugs and [Discussions](https://github.com/DasManPack/chiasm/discussions) for questions or early ideas.
