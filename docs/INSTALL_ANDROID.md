# Install Chiasm on Android

The Android app is currently an early bridge companion for a Chiasm desktop host. The desktop app remains the spatial collection explorer.

## Download and install

1. Open the [Build Android workflow](https://github.com/DasManPack/chiasm/actions/workflows/android.yml).
2. Choose the latest successful run and download the `Chiasm-Android` artifact.
3. Install `Chiasm-Android.apk` on your Android device. Do not install the `.aab`; it is an app-store bundle.
4. If Android blocks the APK, allow your browser or file manager to install unknown apps, then open the APK again.

## Use with Chiasm desktop

Run Chiasm on a computer and connect the Android companion to that desktop host over a trusted local network. The Android workflow artifact is for testing and expires; it is not a public store release.
