# Install Chiasm on Android

The Android app in Chiasm v0.1.0 is an early bridge companion for a Chiasm desktop host. The desktop app remains the spatial collection explorer.

## Download and install

1. Open the [Chiasm v0.1.0 release](https://github.com/DasManPack/chiasm/releases/tag/v0.1.0).
2. Download and install `Chiasm-Android.apk` on your Android device. Do not install the `.aab`; it is an app-store bundle.
4. If Android blocks the APK, allow your browser or file manager to install unknown apps, then open the APK again.

## Use with Chiasm desktop

Run Chiasm on a computer and connect the Android companion to that desktop host over a trusted local network. The Android app is not yet available through an app store.
