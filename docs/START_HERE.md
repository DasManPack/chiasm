# Start with Chiasm

Chiasm is an experimental spatial way to explore a music collection. It is a separate project derived from Melodex, not a Melodex release.

1. Download a test build from the [desktop workflow](https://github.com/DasManPack/chiasm/actions/workflows/desktop.yml).
2. Install the package for your computer and open Chiasm.
3. Add or select a local music folder. Your files stay where they are.
4. Move through the field, focus an album, and follow a link that interests you.

For Android, use the [Android workflow](https://github.com/DasManPack/chiasm/actions/workflows/android.yml). The current Android package is an early bridge companion for a Chiasm desktop host.

See [how Chiasm works](CHIASM.md) or the [10-minute test guide](TESTING.md). Test builds are experimental; macOS packages are not notarized.
