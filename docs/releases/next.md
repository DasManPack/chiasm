# Chiasm v0.1.2 release summary

**Chiasm v0.1.2 public preview.**

Current target version: **0.1.2**.

This preview establishes Chiasm as a distinct spatial-first collection explorer. It opens directly into the field, provides a clear folder-add action, and keeps Melodex-derived library and playback services behind the Chiasm experience. Desktop, Android companion, and Linux packages use Chiasm names and icons.

This is an experimental public preview, not a stable release. First-use, reference comparison, real-library playback, accessibility, and device checks remain open.

The existing `v0.1.0` and `v0.1.1` tags point to historical repository commits and have no published releases. This is the first public installer release for Chiasm.

See [v0.1.2 release notes](v0.1.2.md).
