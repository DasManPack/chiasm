# Next release — Chiasm preview notes

**Chiasm v0.1.0 test build.**

Current target version: **0.1.0**.

This preview establishes Chiasm as a distinct spatial-first collection explorer. It opens directly into the field, provides a clear folder-add action, and keeps Melodex-derived library and playback services behind the Chiasm experience. Desktop, Android companion, and Linux test packages use Chiasm names and icons.

This is an experimental workflow build, not a public release. First-use, reference comparison, real-library playback, accessibility, and device checks remain open.

See [v0.1.0 release notes](v0.1.0.md).
