# Chiasm v0.1.0 public preview

Chiasm is an experimental spatial-first way to explore a local music collection. This is its first separately branded test package, derived from selected Melodex library and playback foundations.

## What is included

- Chiasm name, mark, launcher, package identity, and platform artifact names.
- Desktop launch directly into the spatial album field.
- In-field folder addition, indexing feedback, album focus, playback, Horizon, Trace, and Arc.
- Android bridge companion for a Chiasm desktop host.
- Linux desktop packages.

## Preview status

This is an experimental public preview, not a stable release. The release workflow publishes desktop, Linux, and Android packages after their build and smoke checks pass; those assets may appear shortly after the release page is created. macOS packages are not notarized, and Windows packages are not code signed.

First-use usability, screen-reader review, reduced-motion device review, real-library playback, reference comparison, and small-window layout checks remain open. See the [installation guides](../README.md) and [C11 test protocol](../TESTING.md) before trying the preview.
