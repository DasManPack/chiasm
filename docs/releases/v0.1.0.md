# Chiasm v0.1.0 release candidate (not published)

Chiasm is an experimental spatial-first way to explore a local music collection, developed from Melodex's local library and playback foundations.

This release candidate was not published. The existing `v0.1.0` tag belongs to a historical repository commit, and no Chiasm installer assets were released under this version. The first public installer preview is [v0.1.1](v0.1.1.md).

## What is included

- Chiasm name, mark, launcher, package identity, and platform artifact names.
- Desktop launch directly into the spatial album field.
- In-field folder addition, indexing feedback, album focus, playback, Horizon, Trace, and Arc.
- Android bridge companion for a Chiasm desktop host.
- Linux desktop packages.
