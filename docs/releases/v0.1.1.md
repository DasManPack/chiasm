# Chiasm v0.1.1 release candidate (not published)

Chiasm is an experimental spatial-first way to explore a local music collection, developed from Melodex's local library and playback foundations.

## What's included

- Chiasm name, mark, launcher, package identity, and platform artifact names.
- Desktop launch directly into the spatial album field, with an in-field action for adding a music folder.
- Album focus, local playback, Horizon relationship links, Arc listening routes, and Trace return.
- Find for locating a familiar album in a larger collection, without opening a separate search page.
- An Android bridge companion for a Chiasm desktop host.
- macOS, Windows, Linux, and Android packages.

## Publication status

This candidate was not published. The existing `v0.1.1` tag also belongs to a historical repository commit, and no Chiasm installer assets were released under that version. Use the [v0.1.2 public preview](v0.1.2.md) instead.

The proposed preview notes and remaining acceptance work are preserved in the [v0.1.2 release notes](v0.1.2.md).
