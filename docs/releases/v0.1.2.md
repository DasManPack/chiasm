# Chiasm v0.1.2 public preview

Chiasm is an experimental spatial-first way to explore a local music collection. This is its first public installer release, developed from Melodex's local library and playback foundations.

## What's included

- Chiasm name, mark, launcher, package identity, and platform artifact names.
- Desktop launch directly into the spatial album field, with an in-field action for adding a music folder.
- Album focus, local playback, Horizon relationship links, Arc listening routes, and Trace return.
- Find for locating a familiar album in a larger collection, without opening a separate search page.
- An Android bridge companion for a Chiasm desktop host.
- macOS, Windows, Linux, and Android packages.

## Preview status

This is an experimental public preview, not a stable release. The earlier `v0.1.0` and `v0.1.1` tags belong to historical repository commits and have no release assets; this `v0.1.2` release is the first public installer set.

The macOS packages are not notarized, and the Windows packages are not code signed. Five-listener discovery-loop acceptance, first-use usability, screen-reader review, reduced-motion device review, real-library playback, reference comparison, and small-window layout checks remain open. See the [installation guides](../README.md) and [C11 test protocol](../TESTING.md).
